# MarcoArtiano.github.io

Personal website of Marco Artiano. Plain HTML and CSS, no build step.

## Preview locally

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## Publish

Push the contents of this folder to a repository named `MarcoArtiano.github.io`
and enable GitHub Pages on its default branch. The `.nojekyll` file makes
GitHub serve the files as they are.
